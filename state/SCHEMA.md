# Формат состояния

Состояние агента лежит в git, а не в файловой системе контейнера: сессия,
запускаемая по расписанию, эфемерна и исчезает вместе со всем, что не
закоммичено. Каждый цикл заканчивается коммитом в рабочую ветку.

## cursor.json

| Поле | Смысл |
|---|---|
| `last_cycle_at` | ISO-время конца прошлого цикла. Для заголовка сводки. |
| `channels[id]` | Граница разбора канала, Slack `ts`. Двигается каждый цикл по времени цикла, а **не** по `ts` последнего сообщения: ответ в старом треде иначе утащил бы курсор назад. Новым считается сообщение, у которого больше курсора `ts` или `latest_reply`. |
| `greeted_channels` | Каналы, где агент уже представлялся. Чтобы не здороваться дважды. |

## pending.json

Каждый черновик:

```json
{
  "id": "a1b2",
  "created_at": "2026-08-21T14:03:00+03:00",
  "status": "awaiting",
  "revision": 1,
  "class": "BUG",
  "confidence": "высокая",
  "source": {
    "channel_id": "C099240QR3N",
    "channel_name": "разработка-обсуждение",
    "message_ts": "1786215207.736549",
    "thread_ts": "1786215207.736549",
    "author": "Timur Sattarov",
    "permalink": "https://cobaltlabworkspace.slack.com/archives/C099240QR3N/p1786215207736549",
    "excerpt": "Профиль: не листается список эмблем и рамок"
  },
  "inbox": {
    "channel_id": "U0BK99FCH7F",
    "message_ts": "1786220000.111111"
  },
  "reply_text": "Похоже на баг: не листается список эмблем и рамок в профиле...",
  "jira_draft": {
    "project": "TEAMDEV",
    "issue_type": "Баг",
    "summary": "Профиль: не листается список эмблем и рамок",
    "created_key": null
  },
  "resolved_at": null
}
```

`id` — четыре hex-символа, достаточно, чтобы владелец мог сослаться на карточку
голосом («сделай по a1b2 вот так»), и коротко, чтобы влезало в заголовок.

`inbox.message_ts` нужен, чтобы в следующем цикле найти тред карточки и
прочитать реакции с ответом владельца. Без него черновик становится сиротой:
одобрение будет висеть в инбоксе, а агент его не увидит.
